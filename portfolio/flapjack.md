# Flapjack

**Design the menu like a canvas. Publish it like a site.**

Live: [flapjack.co](https://flapjack.co) · [Open in portfolio](https://tahirkodx.github.io/tahirkodx/#flapjack)

## Problem

Menus still start as a Word file and a designer. The owner wanted a builder that treats layout as the product, not a form of rows.

## What we discussed

Keep the editor visual. Konva owns drag, type, and layout on the canvas. Next.js hosts the app. Zustand holds editor state so the canvas does not fight the page.

## What shipped

A Next.js menu editor with a Konva canvas. Restaurants lay out items visually and publish the result.

## How it was built

Next.js 15, React 19, Konva / react-konva, Zustand, TypeScript, Tailwind.

## How it was deployed

Live at flapjack.co as a Next.js app.
